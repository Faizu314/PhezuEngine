## Manifesto

- **Lightweight**
<br>Minimal dependencies.<br><br>

- **Readability**
<br>Source code should be easy to understand for people trying to get into engine development.<br><br>

- **Full Control**
<br>I want to have full low level understanding over the game that I build. Every line of code + every asset file the executable uses.<br><br>
