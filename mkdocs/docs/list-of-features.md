# Features of PhezuEngine

Here is a list of features that are currently supported.

## Rendering

PhezuEngine has a custom C++ renderer with OpenGL support. There are no plans to support any other graphics API (Except for OpenGL ES)

## 2D Graphics

- Sprite Rendering
- Custom Vertex and Fragment Shaders

## Scripting

- C# Scripting using Mono
- Component based design

## Workflow

- Supports 7 types of assets
    * Prefab
    * Scene
    * Image
    * Texture
    * Shader
    * Material
    * Config
- Prefab system with nesting and overrides
