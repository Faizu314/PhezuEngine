PhezuEngine Documentation

Welcome to the official documentation of PhezuEngine.

Overview

PhezuEngine is a lightweight 2D Game Engine built in C++ with C# scripting. Created as a personal learning project to understand engine architecture. There is a strong focus to keep the codebase as simple and readable as possible so others can use this as a learning resource.

Project Goal

This project aims to write code as simple as possible, this means no uneccessary abstractions, no premature optimisations, no flashy features, no dependencies and no black boxes. Just simple, direct and fully transparent code that tells you a story about how pixels end up on a screen.

The goals for the 1.0 release are not yet fully defined, even though I have some idea of the feature set and the kind of games I would like to build with this engine. I always keep my to-do list up to date and explicitly mention if the timeline for a certain feature is not clear. Visit the road map section for details.

Target Audience

Since I am the sole developer of this project and am developing it for my own use cases, I can only think of two types of target audiences, those who just want to understand how engines work and those who want to make very specific type of simplistic/minimalistic games. Think of pocket tanks, asteroids, neon wars, pong, pac-man, geometry dash, doodle jump, anything with a simple orthographic camera and primitive shapes/sprites.
